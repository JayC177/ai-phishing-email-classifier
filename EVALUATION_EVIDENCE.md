# Evaluation Evidence

This file explains the evidence generated by `phishing_email_classifier.ipynb`.

## Required final-run evidence

After running every notebook cell with the selected public dataset, copy the values from `outputs/test_metrics.json` here:

| Metric | Final held-out test score |
|---|---:|
| Accuracy | Run notebook |
| Precision (phishing) | Run notebook |
| Recall (phishing) | Run notebook |
| F1 (phishing) | Run notebook |
| Test examples | See `outputs/example_predictions.csv` |

The values are deliberately not fabricated in the submitted source package. They must come from the actual held-out test run on the machine used for the experiment.

## Generated artifacts

- `outputs/confusion_matrix.png`: counts of legitimate/phishing predictions by true class.
- `outputs/learning_curves.png`: training and validation loss plus validation F1 by epoch.
- `outputs/classification_report.txt`: per-class precision, recall, F1, and support.
- `outputs/test_predictions.csv`: every held-out email with its true label, prediction, and phishing probability.
- `outputs/false_positives.csv`: legitimate emails incorrectly flagged as phishing.
- `outputs/false_negatives.csv`: phishing emails incorrectly classified as legitimate.
- `outputs/example_predictions.csv`: readable sample predictions.
- `outputs/run_config.json`: model and training settings used.

## Interpretation guide

Phishing recall is especially important because a false negative represents a phishing message that the model failed to flag. Precision is also important because excessive false positives would make the detector disruptive. F1 summarizes the tradeoff between these two values.

## Limitations to discuss with the results

1. The dataset may contain duplicates or repeated templates.
2. A test split from the same source is easier than a truly external test set.
3. Text-only analysis ignores sender, header, URL, attachment, and domain information.
4. Long emails are truncated.
5. Model confidence is not necessarily calibrated.
6. Performance on modern or targeted spear-phishing messages may be lower.
